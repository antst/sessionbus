# Tygo wire DTO generation

`go.mod` pins official `github.com/gzuidhof/tygo` v0.2.21 (upstream commit
`0b55b7f6509c82f14206cc704eb4a230ece9efe4`) independently of the daemon and SDK
runtime modules. `go.sum` locks its Go dependencies. Run through the scripts in
`bus/package.json` to use the correct working directory.

The small Go entry point selects exported type declarations from
`sdk/go/protocol/types.go`, then calls Tygo's `ConvertGoToTypescript`. Selecting
Go declarations before conversion excludes constants and functions: a `.d.ts`
that advertised those values would promise nonexistent JavaScript exports.
Tygo owns field naming, optional properties, aliases and interface generation.
No second list of DTO fields is maintained. The internal parsed `Frame` from
`frame.go` is deliberately outside this JSON DTO surface.

One source hint, `tstype:",extends"`, expresses Go's flattened anonymous
`WorkerHello.HelloDescription` field. Explicit `json.RawMessage` mapping gives
`unknown`; Go `any` uses `unknown`. Unmapped external types fail generation instead
of silently using `any`. Generator tests cover aliases, optional pointers,
embedded structs, JSON names, unknown data and source drift. The build also
compiles a consuming TypeScript fixture from the actual npm tarball. Negative
assertions prove `Caller.list()` exposes generated fields rather than `any`.

`check:types` compares generated bytes without modifying files. Both CI and npm
publication workflows run it. `test:types` uses pinned TypeScript 5.9.3 through
`npm exec` solely as a development compiler; it has no runtime installation or
SDK dependency. The package carries the generated `.d.ts`, usage documentation
and existing runtime JavaScript; it does not carry this generator, test fixture,
Go tool modules or TypeScript compiler. Tygo's MIT license is retained here;
other Go tool dependencies are downloaded through their original modules with
licenses intact and are not redistributed in the npm package.

The runtime JSON schema stays authoritative for constrained strings, numbers,
nullability and cross-field rules. The generated TypeScript shapes intentionally
do not replace either runtime validator. When adding a Go representation Tygo
cannot correctly map, add an explicit Go source hint or mapping and a consumer
regression before accepting regenerated output.
