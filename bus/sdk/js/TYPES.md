# Wire types

DTO declarations are generated by [Tygo](https://github.com/gzuidhof/tygo) from
`sdk/go/protocol/types.go` and shipped in this package. Use a type-only import:

```ts
import type { SessionListResult, SessionSelfInfo } from '@sessionbus/kit/protocol';
```

`protocol` is a **type-only module**; it exports no JavaScript values or constants.
JavaScript consumers can use JSDoc `import('@sessionbus/kit/protocol')` types.
`Caller` methods reference these declarations for request and response shapes,
including `list()` returning `Promise<SessionListResult>`. Existing JavaScript
transport, validation and exports are unchanged. This is not a declaration of the
entire SDK runtime API; projects checking JavaScript SDK implementation files can
use TypeScript's `allowJs` and `maxNodeModuleJsDepth` (the package fixture checks
`Caller` at depth 1).

The declarations describe protocol DTO shapes, not every valid or invalid JSON
value. `session.schema.json` remains the shared Go/JavaScript runtime validation
contract: it enforces required combinations, allowed strings, safe integer
ranges, frame limits and other rules that Go structs alone do not describe.

- JSON field names and `omitempty` come from Go tags. Optional pointers are
  represented as omitted properties, not `null`; current protocol validation
  rejects null for these fields.
- `WorkerHello` embeds `HelloDescription` with a Tygo `extends` source hint to
  match Go's flattened JSON encoding. Defined types and aliases retain references
  to their underlying DTOs (`SessionSelfInfo` uses `DeliverySource`).
- `json.RawMessage` and `any` become `unknown`, so consumers must narrow arbitrary
  JSON before using it. Raw messages are parsed JSON values, not byte arrays.
- Go integer fields become JavaScript `number`, including `int64`; validators
  enforce protocol-safe integer bounds. They are not `bigint`.
- Required slices and maps describe validated non-null arrays/objects. These
  declarations do not describe invalid nil-backed Go values before validation.

`self_info` is optional when reading responses from older daemons. Current
servers supply the originating caller even when filters exclude its session row.
The identity comes from the bound connection; never infer it from list order or
name matching.

To regenerate and check from a source checkout:

```sh
npm run generate:types --prefix bus
npm run check:types --prefix bus
npm run test:types --prefix bus
```

Generation uses a pinned build-only Go tool module; package consumers do not need
Go, Tygo or a new runtime dependency. The test command downloads a pinned
TypeScript compiler for an isolated, temporary installed-package type check.
